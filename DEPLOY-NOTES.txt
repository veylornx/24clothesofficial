Stock control:
- stock > 0: green IN STOCK badge.
- stock = 0: red SOLD OUT badge and Buy Now is disabled.
- API independently reserves stock before creating an order and rejects orders when requested quantity is unavailable.
- After a successful order, stock is reduced by the ordered quantity.

Customer Accounts: customers can register with name, phone, optional email and password; the system issues permanent IDs such as #001. Passwords are bcrypt-hashed. Customers log in with Customer ID + Password and see their account-linked order history. Admin → Customers provides search, order history and password reset. The public registered-customer counter counts real accounts only.

Customer My Orders: new orders are saved automatically in the same browser. Existing orders can be added by verifying Order ID + checkout phone once. Customers can see item/payment/delivery details, status timeline and message the store from the same screen. Admin and customer chats refresh automatically while open.
